📋 ສຸດທ້າຍ Entity ທັງໝົດ

Collection ໜ້າທີ່ ປະເພດ Relationships ຫຼັກ
User ຜູ້ໃຊ້ທຸກ role (user / admin / superAdmin) Main → Order, Product, Review, Blog, Coupon, FinancialTransaction, PushSubscription
Product ສິນຄ້າ IT ທີ່ຈຳໜ່າຍ Main → Category (by slug), ← User (creator), ← OrderItem, ← FlashDeal
Category ໝວດໝູ່ສິນຄ້າ Main ← Product (many products per category)
Order ອໍເດີຂອງລູກຄ້າ — lifecycle ທຸກຂັ້ນຕອນ Main → User, → Coupon, embeds: ShippingInfo, OrderItem[], PaymentProof[], OrderEvent[]
ShippingInfo ທີ່ຢູ່ຈັດສົ່ງ + carrier ທີ່ເລືອກ Embedded in Order — (embedded, ບໍ່ມີ collection ຕ່າງຫາກ)
OrderItem ລາຍການສິນຄ້າໃນອໍເດີ (snapshot ລາຄາ) Embedded in Order → Product (ObjectId ref)
Review ຄະແນນ + ຄຳຄິດເຫັນສິນຄ້າ Embedded in Product → User (reviewer)
PaymentProof ສະຫຼິບການໂອນເງິນ (Cloudinary image) Embedded in Order → User (uploader)
OrderEvent ປະຫວັດ / Timeline ຂອງ Order Embedded in Order → User? (actor — optional admin)
Coupon ລະຫັດສ່ວນຫຼຸດ — percentage ຫຼື fixed Main → User (createdBy), embeds: CouponUsage[]
CouponUsage ຕິດຕາມວ່າໃຜໃຊ້ coupon ໃດ ໃນ Order ໃດ Embedded in Coupon → User, → Order
FlashDeal Flash Sale — array of Product refs + discount% Main → Product[] (many-to-many via array)
Blog ບົດຄວາມ IT — tech, review, guide, news Main → User (authorId), embeds: Comment[], Like[]
BlogComment ຄຳຄິດເຫັນໃນ Blog Embedded in Blog → User
FinancialTransaction ບັນທຶກລາຍຮັບ/ລາຍຈ່າຍ (SuperAdmin finance) Main → User (recorder/admin)
PushSubscription Web Push VAPID subscription ຂອງ User Main → User (1 user, many devices)
🔄

Status Sync (Order)

fulfillmentStatus ເປັນ source of truth.
Pre-save hook auto-sync orderStatus + shipmentStatus (legacy fields) ໃຫ້ match ຕະຫຼອດ.

📦

Embedded vs Referenced

Embedded: Review, OrderItem, PaymentProof, OrderEvent, CouponUsage, BlogComment — ຂໍ້ມູນທີ່ belong to parent ສະເໝີ.
Referenced: User, Product, Coupon, Category — ຂໍ້ມູນທີ່ share ໄດ້.

🔒

ຄວາມປອດໄພ

Auth: Cookie-only httpOnly, ບໍ່ມີ JWT ໃນ localStorage.
Role guard: user / admin / superAdmin.
Order: idempotencyKey ກັນ double-submit.
